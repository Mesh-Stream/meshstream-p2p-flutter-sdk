# Flutter 1.0.7 候选验收

Android 原生依赖升级为已发布 Maven 1.0.8，插件 minSdk 21；Apple 保持公开 CocoaPods MeshStreamKit 1.0.8（runtime 1.0.7），最低 iOS 15。应用系统下限取插件、Flutter、播放器及其他依赖的最高值，当前示例仍为 Android 24。

Flutter 3.47.8 / Dart 3.13.7、Xcode 27.1 / CocoaPods 1.17.0、JDK 17.0.21，当前 Apple Silicon Mac 验证：

- flutter analyze 无问题；Dart 测试 39 项、示例测试 6 项、Android 原生桥接 JUnit 14 项通过。
- 插件 minSdk 21 lint、Android 双 ABI Debug APK 构建通过。
- iOS 模拟器 Debug Runner.app 构建通过，解析公开 MeshStreamKit 1.0.8。
- 首次 Android 构建命中旧 Kotlin 增量缓存，重新执行插件编译后完整构建通过，无 SDK 源码修补。
- 本次无连接真机：iOS / Android 播放、P2P、CDN 回退和关闭释放验收待完成；API 21 真机验收待完成。

本记录为发布前候选结果，pub.dev 发布与公网精确版本安装验证另行更新 releases/1.0.7.json。候选测试使用临时依赖覆盖，覆盖文件不进入发行包或 Git。
