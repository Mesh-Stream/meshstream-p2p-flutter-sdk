# Flutter 1.0.5 发行验证

## 版本与环境

- Flutter 包：`meshstream_p2p: 1.0.5`，发行标签 `1.0.5`。
- 精确公共原生依赖：CocoaPods `MeshStreamKit 1.0.7`、Maven `io.meshstream:meshstream-android-sdk:1.0.6`。
- Android Maven 地址：`https://sdk.meshstream.net/maven`。
- Apple Silicon Mac；Flutter 3.47.8、Dart 3.13.7、Xcode 27.1、CocoaPods 1.17.0、Temurin JDK 17.0.21、Gradle 8.14、AGP 8.11.1、Kotlin 2.2.20、NDK 27.2.12479018。最终 Android 构建的 compile SDK、Build Tools 以发行清单记录为准。
- Android 真机：PFJM10 / Android 13 / arm64-v8a。
- iOS 模拟器：iPhone 18 Pro / iOS 27.0 / arm64。iOS 真机验收待完成。

原生依赖来自已发布的公共 CocoaPods/Maven，没有用内部 Pod/AAR 或原生源码路径替代。适配阶段只对 Flutter 候选包使用本地依赖覆盖；发布后应移除覆盖并从 pub.dev 安装精确版本复验。

## 本地候选包

类型分析通过；Dart 测试 39 项、示例测试 6 项、Android 原生桥接测试 14 项通过。Android ARM64 debug 和 iOS ARM64 模拟器构建通过；iOS 原生桥接 XCTest 16 项通过。

双端使用同一 Mux Big Buck Bunny HLS 媒体清单和独立 content ID，持续采样约 90 秒。为排除公网媒体源的超时干扰，下载公开测试素材并由本机提供 HLS，以每个媒体请求 128 KiB/s 限速；Android 通过 USB reverse 访问源站。Tracker、鉴权和 Peer 传输均使用真实公共服务，不是模拟后端。

| 候选包 P2P 阶段 | Android 真机 | iOS 模拟器 |
| --- | ---: | ---: |
| 最大 Peer | 1 | 1 |
| P2P 下载 | 2,406,588 B | 0 B |
| HTTP 下载 | 2,668,848 B | 13,053,008 B |
| P2P 上传 | 240 B | 2,627,427 B |
| 最后采样播放进度 | 86,696 ms | 84,939 ms |
| Tracker / Peer 错误事件 | 0 / 0 | 0 / 0 |

本轮确认 iOS → Android 媒体分享，Android 下载分流率约 47.4%。上传与下载为异步快照，不能要求字节完全相等。Android 的少量上传字节不能证明反向媒体分享；Android → iOS 媒体传输尚未验收。可控源条件下的分流率不能作为生产网络的固定性能结论。

随后双端调用 `setP2pEnabled(false)` 并跳转到后续 VOD 位置，避免仅凭已缓冲内容判定 CDN 回退成功：Android HTTP 增加 783,600 B，iOS 增加 793,188 B；Peer 均为 0，跳转后的实际播放继续推进超过 5 秒，没有播放器错误。

双端验证：关闭一个会话后同客户端的兄弟会话与另一个客户端仍可用；关闭客户端后其会话拒绝访问，另一个客户端继续可用。最后所有 player/session/client 均关闭，双端集成测试退出码为 0。

## 调试过程中遇到的环境情况

- 手机已有旧 Flutter Demo，与本机签名不同。本次设备测试使用独立的 `net.meshstream.flutter.releasecheck` 应用 ID，保留旧应用数据；公共源码保留标准示例 ID。手机上交付的正常 Demo 不使用自动化测试入口。
- ADB 37 在当前 macOS 上崩溃导致一次测试中断；改用本机 ADB 35.0.2 的 Rosetta 服务完成验收。保留失败日志，不以中断测试宣称通过。
- 公网 Mux 源曾导致 Android 播放器 `SocketTimeoutException`；首次 iOS 公网源测试完成播放、P2P 上传、回退及隔离。其余完整配对验收采用上述可控源。
- 不限速的本机源会在 P2P 就绪前让 iOS 预读完整视频；该轮连接到 Peer 但没有媒体交换，未通过分享断言。最终通过记录来自限速重跑。
- Flutter 提示未来将提高 Gradle/AGP/Kotlin 支持下限、未来要求插件 SPM 适配，以及 integration_test 建议更高 NDK；当前约定工具链构建与测试已实际通过。未把这些提示当作完成未来工具链适配。
